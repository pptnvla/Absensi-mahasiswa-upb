# 📋 Aplikasi Absensi Sederhana 2.0

Sistem Pencatatan Kehadiran Mahasiswa berbasis Web yang dikembangkan menggunakan HTML, CSS, dan JavaScript murni tanpa bantuan _framework_ tambahan. 

Aplikasi ini dibuat sebagai tugas mata kuliah **Pemrograman Web** pada Semester 5.

## ✨ Fitur Utama
1. **Sistem Autentikasi**: Halaman login interaktif dengan fitur penampil *password* (mata) dan keamanan halaman.
2. **Dashboard Interaktif**: Menampilkan rangkuman total kehadiran, persentase kehadiran, grafik batang komparasi per status (murni CSS), dan 5 entri absensi terakhir.
3. **Pencatatan Kehadiran Cerdas**: Formulir lengkap yang mencakup perhitungan kalkulasi otomatis menggunakan logika dan operator (*AND, OR, NOT*).
4. **Riwayat Tersimpan Lokal**: Data absensi langsung tersimpan di `localStorage` peramban (*browser*), menjamin tidak akan hilang meski laman disegarkan (*refresh*).
5. **Penyaringan (*Filter*) Real-Time**: Fitur pencarian instan berdasarkan Nama, NIM, atau Status pada tabel Riwayat.
6. **Desain Modern & Responsif**: Menggunakan tren *Glassmorphism*, palet gradasi ungu-biru, animasi mulus, serta menyesuaikan optimal untuk layar HP dan Desktop.

## 🚀 Cara Menjalankan Aplikasi
Aplikasi ini hanya memanfaatkan teknologi peramban dasar, sehingga tidak membutuhkan *server* atau aplikasi *backend* apa pun.

1. Buka folder `Absensi-Sederhana` yang Anda ekstrak atau _clone_.
2. Cari dan klik dua kali (_double click_) pada file **`index.html`** atau **`login.html`**. File akan otomatis terbuka di peramban (contoh: Google Chrome, Mozilla Firefox).
3. Anda akan disambut halaman masuk. Gunakan kredensial demo berikut:
   * **Nama Pengguna**: `admin`
   * **Kata Sandi**: `admin123`
4. Selamat, Anda berhasil masuk ke Dashboard dan dapat mulai mengelola data absensi!

## 💻 Teknologi yang Digunakan
- **HTML5**: Struktur laman semantik.
- **CSS3 Vanilla**: Penataan gaya dengan sistem CSS Variabel, transisi, bayangan (*shadow*), tata letak *flexbox/grid*, dan media *queries*.
- **JavaScript Vanilla**: Logika pemrosesan angka, validasi, dan sinkronisasi `sessionStorage` & `localStorage`.
