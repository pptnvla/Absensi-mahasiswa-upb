Tujuan Aplikasi

Membantu pencatatan dan pemantauan kehadiran mahasiswa secara digital dengan kalkulasi otomatis persentase dan kelayakan ujian.

📚

Mata Kuliah

Proyek ini merupakan tugas Pemrograman Web Semester 5, Program Studi Teknik Informatika, Universitas Pelita Bangsa.

💾

Penyimpanan Data

Seluruh data absensi tersimpan di localStorage browser secara lokal, tanpa perlu koneksi internet atau server.

📱

Responsif

Antarmuka menyesuaikan ukuran layar otomatis — dari monitor desktop besar hingga layar ponsel kecil.

💻

🎨 CSS3 Vanilla — Gaya & Animasi

Fitur Utama Aplikasi
  • 🔐
    Sistem Login Aman — Autentikasi dengan validasi operator OR, NOT, dan minimal karakter. Fitur toggle tampil/sembunyi password.
  • 📊
    Dashboard Interaktif — 6 kartu statistik (Total, Rata-rata, Hadir, Izin, Sakit, Alfa) + grafik batang CSS murni + 5 entri terbaru.
  • ✏️
    Input Absensi Cerdas — 6 komponen form, kalkulasi otomatis persentase & kategori, progress bar hasil, tersimpan otomatis.
  • 📂
    Riwayat & Filter Real-Time — Cari nama/NIM, filter status & kelayakan, nomor urut, tombol hapus per baris, hapus semua.
  • 🧮
    Validasi Logika Lengkap — Menggunakan operator AND (&&), OR (||), NOT (!) untuk validasi input dan penentuan kelayakan ujian.
  • 🎨
    Desain Premium — Tema biru-ungu, glassmorphism login, grafik CSS, animasi fadeSlideUp, badge berwarna, font Inter.
  • 📱
    Responsif Mobile — Sidebar overlay, tata letak fleksibel, footer rapi di semua ukuran layar.
🔢
Operator Logika JavaScript
✅
AND (&&)
Layak ujian jika kehadiran ≥ 75% dan tugas sudah dikumpulkan. Kedua syarat harus terpenuhi.
🔀
OR (||)
Error jika salah satu kolom kosong. Belum layak ujian jika persentase < 75% atau tugas belum selesai.
🚫
NOT (!)
Validasi NIM: jika bukan angka maka error. Peringatan jika tugas belum dikumpulkan meski hadir cukup.
